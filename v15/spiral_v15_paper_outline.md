## 一、定位：这篇稿子主张什么，不主张什么

**主张**（方法学）：给分层科学计算流水线的**每一层**配上"能在结论不成立时失败"的对照，
并把"配不上的地方"连同成因一并登记 —— 这套做法本身是可以复用、可以照抄的工程方法。

**不主张**（关键，防跑偏）：
- ❌ **不主张"七层涌现框架成立"**。七层的成熟度实测是 A×1 / B×3 / C×3 / D×0（审计表 §1）。
- ❌ **不主张 L4→L5 建立了全息桥梁**。B1 侦察结论见 §五：那条线上**没有上游派生的量在流动**。
- ❌ **不主张"100% 通过率"代表证据变强**。100% 的含义只是 54 条计分断言成立（审计表 §0）。
- ❌ **不主张任何宇宙学结论，也不交代宇宙学出处**。标题、摘要、引言**全部零宇宙学**
  （2026-09-19 已定：**连 provenance 那一句也不留**）。

**这篇稿子的诚实起点**（照抄 `_v15_anchor_external.py` 的汇总口径）：

> 有外部锚点的那 5 条，锚的都是**横场 Ising 临界性** —— 而那是**教科书内容**。
> 项目自称新意的 L4→L5 全息桥梁、L1 接线，在锚点表里**一条都没出现**，
> 因为它们目前是空的 / 零结果，**没有可锚的读数**。

所以稿子的正确姿态是：**基底物理是教科书级的、被外部锚点钉死；新意在方法层，不在物理层。**

## 二、标题与摘要（去宇宙学）

### 2.1 标题

**建议（中文）**：

> **逐层负对照台账：让模拟流水线的每一条结论都可证伪**
> ——以临界横场 Ising 链上的七层派生流水线为示范

**建议（英文）**：

> **A per-layer negative-control ledger: making every claim in a simulation
> pipeline falsifiable — demonstrated on a seven-layer derivation pipeline
> for the critical transverse-field Ising chain**

**选词理由（每条都对着稿子里真有的东西）**：
- "逐层" —— 台账按七个物理阶段归位，且逐层报出哪几层**没有**对照（审计表 §2 P2-2）。
- "负对照台账" —— 是一个具体的代码产物（`_NEG_CTRL_TABLE` + `metric_negative_control_ledger`），
  不是形容词。
- "可证伪" —— 判据写死在代码里：**必须能在结论不成立时失败**（§三）。
- 副标题里的"示范"是**认怂也是护身**：TFIM 是基底，不是卖点。

**备选标题**（若审稿方向偏软件工程）：「从 sanity check 到负对照：分层计算流水线的可证伪性工程」

### 2.2 摘要（草案，约 200 字）

> 多阶段科学计算流水线里，每一层都产出一个"派生量"并交给下游消费；但"这一层算对了"
> 通常只由**正性 / 有限性 / 非空**这类检查把守 —— 而这类检查在结论不成立时**不会失败**。
> 我们给"负对照"立一条可操作的判据：**它必须能在结论不成立时失败**；据此把
> **单纯的正性/有限性/非空检查排除在外**，并把对照分为四类（推离 / 零模型 / 二路径 / 上界）。
> 台账另配一条**完整性守卫**（引用的守卫名必须真实存在于运行期注册表、且七层各出现一次），
> 防止台账被写成宣传册。**守的命题实测为假的检查，一律登记为"诊断项"、不计入通过率分母**
> —— 否则就是挑容易过的检验给自己抬分。
>
> 我们在一套七层派生流水线上示范该方法，验证基底是临界横场 Ising 链
> （精确对角化 + 张量网络）。**结果**：54 条计分断言全部成立、18 项指标达标、12 条负对照
> 覆盖 7 层中的 6 层；基底被外部锚点钉死 —— 基态能密度在**每一个 L 上**都落在无自由参数的
> CFT 有限尺寸公式 `e_∞ − πcv/(6L²)` 上（L=16 相对残差 1.8e-6，残差反解幂次 p=4.00）；
> 低能能谱给出**独立于纠缠谱族**的第二把尺子测中心荷（偏差 0.212%，对照 Rényi 族 7.97%）。
> **我们同时报告三类负面结果**：某层的对照**造不出来**（该层到下游没有因果通路，
> 已给出成因）；某层的"几何"读数**不依赖被拟合的态**（它只是二进制网络布局的解析性质，
> 故不能读作"涌现出来的几何"）；以及两处**自相矛盾的口径**被改正。
>
> **边界**：100% 指 54 条计分断言成立，**不是**系统的证据变强。

**摘要里刻意没写的**（同样是写作决定，值得记下）：
- 不提宇宙学 —— 一句都没有。
- 不提"全息对偶" —— 因为 B1 查出那条线上没有上游量在流动（§五）。
- 不提"提升成熟度" —— 本轮工作**没有把任何一层从 B 变成 A**（审计表 §8）。

### C4（示范物理 · 最硬的一条）逐 L 对上无自由参数的 CFT 有限尺寸公式

| 项 | 内容 |
|---|---|
| 主张 | 基态能密度在**每一个 L 上**都落在 Ising CFT 的有限尺寸预测上 |

| 负对照 | 脚本含 `--selftest` **非恒真证明**；外部常数不参与产生 E0（E0 由精确对角化给出） |
| 诚实边界 | **这比代码里原有的锚点强** —— 原有的只把外推的 e_∞ 对 −4/π（偏差 5.0e-6），这里对的是**逐 L 的 1/L² 系数**（含 c 与 v 的乘积）。**但这仍只是"ED 算对了"**，是教科书内容，不是本文新意 |
| 置信度 | ✅ 本轮实跑 `_v15_anchor_external.py` |

### C9（负面结果 · 必报）某层的"几何"读数不依赖被拟合的态

| 项 | 内容 |
|---|---|
| 主张 | 该读数描述的是**二进制网络的接线布局**，不是"涌现出来的几何" |

## 五、B1 结论（本轮侦察，直接决定 §3.1 怎么写）

**证据三（本轮新查）：线上没有上游派生的量。** 我提出的疑点是：L5 用
`mera_init(32, 2, ...)`（**chi 写死为 2**），而 L4 派生的键维是 **chi_dev = 4**
（面积律 exp(S)=2.1171 → 4）；grep 全文件确认 `chi_dev` 的消费者是
`v13_tier1_runs`(:3501) / `cross_boundary_twist`(:3637) / `s4`(:3512,:3514)，
**没有一个流向 :3485**。

**这个疑点被我自己最便宜的否证法推翻了**（先 `_v15_probe_b1_chi_graph.py` 探测，
后**接进产物代码**）：

```
L= 8 / 16 / 32, chi ∈ {2,4,8}:  边集与 chi=2 逐位相同  => G 与 chi 无关
分辨力对照: L=8 vs L=16 边集不同                            => 探测不是恒真
num_tensors = 2L-2 精确成立 (L=16→30, L=32→62)
```

二进制 MERA 的**接线图只依赖 L 与布局**，chi 只定指标维度、不定接线。所以
chi=2 与 chi=4 给出**逐位相同的图**，chi 不一致**无害**。

**本轮（任务①）把这条测量从一次性探测搬进了产物代码**，理由是纪律性的：
探测脚本里的数字若抄进 F6d 的 note 就是**硬编码**，而本项目的规矩是"condition 串由
产物代码自己算出"。做法是在 `spiral_model_v15.py` 新增 `mera_bulk_invariance(L, seeds, chis)`，
在 `main()` 里运行期调用、把整个字典落进 `s5['bulk_seed_invariance']`，F6d 的
condition 与 note 由它插值而来（含 `chis` / `chi_same` / `n_nodes` / `nodes_match_binary_mera`）。
**旧键 `same` 保留**，故 F6 既有消费者不必改签名。守卫名相应从
"`mera_bulk` 依赖态"改为"**依赖态或键维**"。已核：台账 `_NEG_CTRL_TABLE`
（`spiral_metric_v15.py:3901-3903`）**只引用 F6a/F6b/F6c，不含 F6d**，故改名不会让
"台账完整性"那条守卫翻；`_v15_smoke_w10.py` 用 `startswith('F6d')` 匹配，仍命中。
**该函数体内用 `try/finally` 存还 torch RNG**（`mera_init` 会调 `torch.manual_seed`，
额外构造会把全局状态留在最后一个 seed 上）—— 冒烟实测调用前后 RNG 状态**逐位相同**。

**但否证把结论钉得更死了。** 把三个实测并排：
- G 不依赖 **chi**（本轮探测）
- G 不依赖 **seed**（W10 实测，F6d）
- G 不依赖 **态**（W10：`build_mera_graph` 只读 `ind_map`，`mera_fit*` 只调 `t.modify(data=...)`，从不改接线）
- `num_tensors = 2L−2`、**三角 = 0**（解析）

⇒ **L5 的"体几何"读数是 (L, 二进制布局) 的纯解析函数**，L=32 唯一确定它。
**L4 派生的那个量从来没有流进 L5。**

**与 L1 的区别（这是本问的核心）**：

| | L1 | L4→L5 |
|---|---|---|
| 通路 | **无因果通路**（`equal_state` 无消费者） | **通路完整**（图 → 曲率 → json 全在） |
| 对照 | **造不出来**（没有可推离的量） | **造出来了，且是七层最强**（三类零模型 ×3，双侧） |
| 缺的性质 | 缺**工具** | 缺**对口** |

**一句话**：**L1 是"空得有理由"；L4→L5 是"填得很足，但填在了另一个问题上"。**
这两类**不能合并成同一个"缺口"**去汇报。

**置信度**：
- 证据一（桥接着）、证据二（对照与判定值）：**代码已实现 + 日志实测，高**
- "线上没有上游派生的量在流动"：**逻辑推断**（基于"G 与 chi/seed/态 三者都无关"三个实测），**高**
