## 3. 第三层 A 段：口径再变一次（必读）

| 口径 | D_struct | 参考侧噪声底 | d′ |

**v15 做了什么**：参考侧从"自建种子"再进一步，换成与模型侧**逐字同参数同单位**的受控重算
（`L=0.5, Du=2e-5, Dv=1e-5, F=0.035, k=0.06, T_phys=40000`），**只变网格 N**，
`dt` 随 h² 同比缩以保持 `stab` 相同。两侧每格物理长度差 252 倍的问题由此消除。

**硬核对（零开销）**：N=36 恰是模型侧派生值，其 seed 0 与模型侧 `s6['v']` **逐点差严格 0.0**。

**实测**：逐 N 受控距离 0.3369 / 0.3055 / 0.3701，**全部小于**同 N 种子散布
0.3900 / 0.4862 / 0.4450（比值 0.86 / 0.63 / 0.83）；跨 N 距离 0.2906 / 0.3655 / 0.2868
—— **分辨率变化落在初值噪声内**。

**结论方向必须说准**：这不是"模型变好了"，而是**旧口径那条距离里的大部分来自混杂因子**
（相区参数不同、CLIP 侧 phi 0.64~0.92 而非 0.5、盒子与网格不同、单位制不同）。
受控之后模型侧**只是同一分布里的一次普通抽样**。

**边界三条**：
1. **这是一条零结果**。它消掉的是混杂，**没有**建立 L4 与全息对偶之间的桥梁 ——
   审计表对 L4 的批评里"桥梁为空"那半句**完全没动**。故 L4/L5 维持 C。
